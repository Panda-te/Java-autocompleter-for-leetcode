# Java LeetCode Auto Completor

A lightweight tool designed to speed up **Java coding on LeetCode** by automatically generating the required Java boilerplate and completing the standard class/method structure.

The goal is to let you focus on the **solution logic** instead of repeatedly writing the same LeetCode template.




## 🚀 Installation
 ## Step1 -  
 Download it in zip and extract.
 ## Step2 -
 Just go to extensions and load unpack the extension.
 you are set
